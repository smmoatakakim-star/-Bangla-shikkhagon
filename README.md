# বাংলা শিক্ষাগর (Bangla Shikkhagor) — বাংলাদেশ স্কুল লার্নিং প্ল্যাটফর্ম

৬ষ্ঠ থেকে ১০ম শ্রেণির শিক্ষার্থীদের জন্য সম্পূর্ণ বাংলাদেশ স্কুল লার্নিং ও প্র্যাকটিস প্ল্যাটফর্ম। এতে রয়েছে এনসিটিবি (NCTB) পাঠ্যসূচি ভিত্তিক অধ্যায়ভিত্তিক নোট, বিষয়ভিত্তিক পড়াশোনা, ১০০০+ এমসিকিউ প্রশ্নব্যাংক, মডেল টেস্ট, কাস্টম কুইজ ক্রিয়েটর, এআই স্টাডি চ্যাট অ্যাসিস্ট্যান্ট, ফর্মুলা ব্যাংক, বুকমার্ক ও প্রগ্রেস ট্র্যাকিং।

---

## 🚀 প্রধান ফিচারসমূহ (Key Features)

1. **শ্রেণিভিত্তিক শিক্ষা (Class 6 - 10):**
   - ৬ষ্ঠ, ৭ম, ৮ম, ৯ম ও ১০ম শ্রেণির সকল প্রধান বিষয় (বাংলা, ইংরেজি, গণিত, বিজ্ঞান, বাংলাদেশ ও বিশ্বপরিচয়, আইসিটি, পদার্থ, রসায়ন, জীববিজ্ঞান ইত্যাদি)।
2. **অধ্যায়ভিত্তিক শিখন সামগ্রী:**
   - প্রতিটি অধ্যায়ের সারসংক্ষেপ, গুরুত্বপূর্ণ সূত্র, প্রশ্নোত্তর ও পরীক্ষার প্রস্তুতি টিপস।
3. **১০০০+ এমসিকিউ ও মডেল টেস্ট:**
   - টাইমার সহ রিয়েল-টাইম কুইজ, সঠিক/ভুল উত্তরের তাৎক্ষণিক ব্যাখ্যা ও প্রগ্রেস অ্যানালিটিক্স।
4. **এআই স্টাডি অ্যাসিস্ট্যান্ট (AI Study Chat):**
   - শিক্ষার্থীদের পড়ালেখা সংক্রান্ত প্রশ্নের তাৎক্ষণিক উত্তর ও ব্যাখ্যা দেওয়ার জন্য নির্মিত।
5. **এসএসসি ও এইচএসসি স্পেশাল হাব:**
   - এসএসসি ও এইচএসসি পরীক্ষার্থীদের জন্য সাজানো সাজেশন, শর্ট সিলেবাস গাইড ও প্রস্তুতি।
6. **ফর্মুলা ব্যাংক (Formula Bank):**
   - গণিত ও বিজ্ঞানের গুরুত্বপূর্ণ সকল সূত্রের তালিকা ও সার্চিং সুবিধা।
7. **ইউজার ড্যাশবোর্ড ও প্রগ্রেস ট্র্যাকিং:**
   - বুকমার্ক করা অধ্যায়, কুইজের স্কোর হিস্ট্রি এবং ডার্ক/লাইট মোড সমর্থন।
8. **GitHub Connection Checker & Integration:**
   - অফিসিয়াল GitHub REST API ও OAuth সমর্থন।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

- **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Backend:** Node.js, Express, Multer, Cookie Parser
- **Database & Auth:** Firebase Firestore, Firebase Authentication
- **AI Integration:** Google Gemini API (`@google/genai`)

## 💻 লোকাল মেশিনে ইনস্টল ও চালানোর নির্দেশিকা

### পূর্বশর্ত:
- Node.js (v18 বা তদূর্ধ্ব)
- npm বা yarn বা bun

### ১. ডিপেন্ডেন্সি ইনস্টল করুন:
```bash
npm install --legacy-peer-deps
```

### ২. এনভায়রনমেন্ট ভ্যারিয়েবল সেটআপ:
`.env.example` ফাইলটি কপি করে `.env` তৈরি করুন:
```bash
cp .env.example .env
```
প্রয়োজনীয় কি-গুলো (যেমন `GEMINI_API_KEY`, `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`) পূরণ করুন।

### ৩. ডেভেলপমেন্ট সার্ভার চালু করুন:
```bash
npm run dev
```
এরপর ব্রাউজারে `http://localhost:3000` ওপেন করুন।

### ৪. প্রোডাকশন বিল্ড তৈরি:
```bash
npm run build
```

## 🔥 Firebase Deploy নির্দেশিকা

এই প্রজেক্টে Firebase Hosting ও Firestore Rules কনফিগার করা আছে:
```bash
# Firebase CLI ইনস্টল না থাকলে:
npm install -g firebase-tools

# লগইন করুন:
firebase login

# ডিপ্লয় করুন:
firebase deploy
```
